# ATERL Science Hub

ATERL 官方站点：Aterl-DistSim 精馏装置仿真与控制系统（开源学习项目）。

- 站点入口：index.html
- 许可：Apache-2.0
- 本地部署 · 无云端依赖

## 结构

```
index.html      页面
style.css       样式
main.js         中英切换 / 动画 / 模块切换
effects.js      鼠标视差 / 时间轴 / 世界地图
assets/         LOGO 与软件截图
CNAME           GitHub Pages 自定义域名
```
